# Financial Models

Workspace for building financial models — operating models, valuations (DCF /
LBO / comps), fundraise & cap-table models, unit economics, forecasts and
scenario analysis.

Comes with a specialist **`financial-modeler`** agent. To use it, open this
folder with Claude Code and ask it to build or review a model — e.g.
"build a 3-statement model for a SaaS company" or "size a £2m seed raise and
show the dilution".

## Structure
| Folder | What goes here |
| --- | --- |
| `models/`  | Model files (Excel, Sheets, notebooks) |
| `data/`    | Inputs and source data |
| `docs/`    | Assumptions memos / write-ups |
| `scripts/` | Reusable Python model builders |
